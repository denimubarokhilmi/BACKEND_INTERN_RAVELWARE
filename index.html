Entity Relationship Diagram
Struktur data di InfluxDB (time-series model)
erDiagram PANEL { string pmCode PK string floor string location string status } POWER_READING { timestamp time PK string pmCode FK float kw float kwh float ampere float voltage } DAILY_SUMMARY { date date PK string pmCode FK float energy_usage int cost } MONTHLY_SUMMARY { string yearMonth PK string pmCode FK float total_energy int total_cost } PANEL ||--o{ POWER_READING : "has many" POWER_READING }o--|| DAILY_SUMMARY : "aggregated into" DAILY_SUMMARY }o--|| MONTHLY_SUMMARY : "rolled up into"
MEASUREMENT: power_consumption
Field/Tag Tipe Keterangan
pmCode TAG Identifier panel (dipakai untuk filter)
kw float Power dalam kilowatt
kwh float Akumulasi energi dalam kWh
ampere float Arus listrik (i.pop() dari array)
voltage float Tegangan (v.pop() dari array)
_time AUTO Timestamp disimpan otomatis InfluxDB
LOGIKA KALKULASI
Field Formula
statusPanel OFFLINE jika lastUpdate > 5 menit lalu
today usage kwh_latest − kwh_first (00:00 hari ini)
cost (default) today_usage × 1.500
daily energy kwh_last_hari − kwh_first_hari
monthly energy Σ daily_energy semua hari
cost (monthly) monthly_energy × 1.500
04
API Endpoints
Dokumentasi detail per endpoint beserta contoh request & response
GET /api/dashboard/panel/:panelId Ambil data dashboard panel listrik
PATH PARAMETER
Nama Tipe Wajib Keterangan
panelId string Required ID panel: PANEL_LANTAI_1, PANEL_LANTAI_2, atau PANEL_LANTAI_3
QUERY PARAMETERS
Nama Tipe Wajib Format Keterangan
month string Optional* jan|feb|mar...
atau 1–12 		Bulan yang diminta. Wajib jika year diisi.
year string Optional* 4 digit YYYY Tahun yang diminta. Wajib jika month diisi.
BEHAVIOR BERDASARKAN PARAMETER
Tanpa param → Kembalikan data hari ini (today's usage), energy = 0, cost = today usage × 1.500
?month&year → Kembalikan energy & cost bulanan. Energy = Σ daily usage, cost = energy × 1.500
Salah satu → Error 400: parameter tidak lengkap
Format salah → Error 400: format month/year tidak valid
CONTOH REQUEST
# Default — data hari ini GET /api/dashboard/panel/PANEL_LANTAI_1 # Filter bulan Februari 2026 GET /api/dashboard/panel/PANEL_LANTAI_1?month=feb&year=2026 # Filter dengan angka bulan GET /api/dashboard/panel/PANEL_LANTAI_2?month=2&year=2026
